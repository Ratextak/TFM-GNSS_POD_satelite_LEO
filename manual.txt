GNSS-FLEX RINEX Processing
==========================

Descripción
-----------
Este repositorio permite procesar archivos RINEX de múltiples receptores GNSS,
generar plots de observables, PVT y comparaciones entre receptores.

Incluye:
- Procesamiento individual de RINEX.
- Comparación de observables entre receptores.
- Estructura de resultados organizada por receptor y comparación.

Requisitos
----------
- MATLAB R2020b o superior.
- Funciones dependientes:
    - RINEX_process_postproc
    - compare_rinex_observables
- Sistema operativo compatible con MATLAB (Windows recomendado por rutas de ejemplo).

Estructura de Carpetas
----------------------
gnss-flex/
│
├─ data/
│   └─ CEDEA/
│       ├─ vuelo_2_eme_rx_basic/
│       │   └─ run_2025-02-05_00-25-57/
│       │       └─ *.obs
│       ├─ vuelo_2_eme_rx_adv/
│       │   └─ run_2025-07-05_00-18-38/
│       │       └─ *.obs
│       └─ vuelo_2_mosaicX5/
│           └─ *.obs
│
├─ results/
│   └─ plots/
│       ├─ figuras individuales por receptor (generadas automáticamente)
│       │   ├─ figures_rx_basic/
│       │   ├─ figures_rx_advanced/
│       │   └─ figures_mosaicX5/
│       └─ comparaciones automáticas por par de receptores
│           ├─ figures_comparision_SCRAB_II_Basic_Rx_vs_SCRAB_II_Advanced_Rx_GPS/
│           ├─ figures_comparision_SCRAB_II_Basic_Rx_vs_SCRAB_II_Advanced_Rx_GAL/
│           └─ ...

├─ src/
│   └─ funciones MATLAB (.m)

└─ main_compare_RINEX.m

Preparación de Datos
-------------------
1. Colocar los archivos RINEX (*.obs) en la carpeta correspondiente dentro de data/CEDEA/.
2. Mantener la estructura de carpetas de cada receptor y ejecución (run), por ejemplo:
   data/CEDEA/vuelo_2_eme_rx_basic/run_2025-02-05_00-25-57/GSDR036a25.25O
3. Actualizar la variable 'receptors' en main_compare_RINEX.m si se añaden nuevos receptores o archivos, indicando:
   - Nombre del receptor (name)
   - Carpeta donde está el RINEX (folder)
   - Nombre del archivo (file)

Configuración de Resultados
---------------------------
- Base de resultados: results/plots/
- Cada receptor genera automáticamente una carpeta individual:
    - results/plots/figures_rx_basic/
    - results/plots/figures_rx_advanced/
    - results/plots/figures_mosaicX5/
- Cada comparación genera su carpeta automáticamente:
    results/plots/figures_comparision_<Receptor1>_vs_<Receptor2>_<Sistema>/
    Ejemplo: figures_comparision_SCRAB_II_Basic_Rx_vs_SCRAB_II_Advanced_Rx_GPS

Opciones de Ejecución
---------------------
Dentro del script main_compare_RINEX.m:

options.SAVE_PLOT       = 1;  % Guardar gráficos (1=Sí, 0=No)
options.CLOSE_at_END    = 0;  % Cerrar todas las figuras al final (1=Sí)
options.SAVE_VIDEO_SKYPLOT = 0; % Guardar skyplot en video (1=Sí)

Ejecución
---------
1. Abrir MATLAB en la carpeta raíz gnss-flex/.
2. Ejecutar el script:

   main_compare_RINEX

3. Los resultados se guardan automáticamente en results/plots/.

Añadir Nuevos Receptores
------------------------
1. Copiar los archivos RINEX a data/CEDEA/<receptor>/<run>/.
2. Añadir la entrada correspondiente en la estructura 'receptors' en main_compare_RINEX.m.
3. Ejecutar el script. Las figuras y comparaciones se generan automáticamente.

Notas
-----
- Las rutas están definidas de forma relativa a la carpeta raíz del repositorio.
- Mantener la estructura de carpetas para que el script funcione sin modificaciones.
- Las comparaciones entre receptores se generan automáticamente para cada par definido en compare_pairs.
