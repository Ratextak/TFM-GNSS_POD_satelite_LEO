x_samples_to file uhd. example of use

rx_samples_to_file is a UHD (USRP Hardware Driver) example program that receives RF samples from a USRP device and saves them to a file. It’s commonly used for testing SDR setups or capturing raw IQ data.

The program is included with UHD examples (usually in uhd/host/examples).
Basic Syntax

rx_samples_to_file [options]

Common options:
Option	Description
--file	Output file where samples are saved
--type	Sample format (e.g., float, short, double)
--rate	Sample rate in samples per second
--freq	Center frequency
--gain	RX gain
--nsamps	Number of samples to capture
--duration	Capture time instead of sample count
--args	Device arguments (e.g., serial or type)
Example 1 — Capture 1 million samples

rx_samples_to_file \
  --freq 100e6 \
  --rate 1e6 \
  --gain 30 \
  --nsamps 1000000 \
  --file samples.dat

This will:

    Tune USRP to 100 MHz

    Sample at 1 MS/s

    Use gain = 30

    Capture 1,000,000 samples

    Save to samples.dat

Example 2 — Capture for 10 seconds

rx_samples_to_file \
  --freq 433e6 \
  --rate 2e6 \
  --gain 20 \
  --duration 10 \
  --file capture.dat

Captures 10 seconds of data at 433 MHz.
Example 3 — Specify USRP device

rx_samples_to_file \
  --args "type=b200" \
  --freq 915e6 \
  --rate 1e6 \
  --gain 40 \
  --duration 5 \
  --file rx.iq

--args selects the USRP device (here a B200).

You can also specify:

--args "serial=30F1234"

Example 4 — Save float IQ samples

rx_samples_to_file \
  --freq 2.4e9 \
  --rate 5e6 \
  --type float \
  --duration 2 \
  --file wifi_capture.fc32

Formats:

    short → sc16 (16-bit complex)

    float → fc32

    double → fc64

Typical Workflow

    Capture samples

rx_samples_to_file --freq 100e6 --rate 1e6 --duration 5 --file test.dat

    Analyze in Python / MATLAB / GNU Radio

Example Python:

import numpy as np

data = np.fromfile("test.dat", dtype=np.int16)
iq = data[0::2] + 1j*data[1::2]

Para capturar GPS L1 (1575.42 MHz) con rx_samples_to_file a 8 MS/s, puedes usar un comando como este.
Ejemplo básico

rx_samples_to_file \
  --freq 1575.42e6 \
  --rate 8e6 \
  --gain 40 \
  --type short \
  --duration 10 \
  --file gps_l1_capture.sc16

Qué hace cada parámetro
Parámetro	Valor	Explicación
--freq	1575.42e6	Frecuencia GPS L1
--rate	8e6	Muestreo a 8 MSPS
--gain	40	Ganancia RX (ajústala según tu LNA/antena)
--type	short	Formato SC16 (int16 complejo)
--duration	10	Captura 10 segundos
--file	archivo	IQ guardado
Si usas un USRP B200/B210

rx_samples_to_file \
  --args "type=b200" \
  --freq 1575.42e6 \
  --rate 8e6 \
  --gain 45 \
  --duration 20 \
  --file gps_l1_8msps.dat

Número de muestras exacto (ejemplo)

Si prefieres N muestras exactas:

GPS a 8 MSPS durante 1 segundo:

8,000,000 samples

Comando:

rx_samples_to_file \
  --freq 1575.42e6 \
  --rate 8e6 \
  --gain 40 \
  --nsamps 8000000 \
  --file gps_l1_1s.dat

Recomendación importante para GPS

Las señales GPS son muy débiles (~ -130 dBm).

Normalmente se usa:

    Antena GPS activa

    LNA

    Ganancia USRP moderada

Ejemplo típico:

gain = 40–55
